# Ressources pour aller plus loin

## Livres
- *The Linux Command Line* — William Shotts (gratuit, <https://linuxcommand.org>) : excellent complément des modules 01-10.
- *How Linux Works* — Brian Ward : comprendre le noyau, le démarrage, le réseau, le stockage (modules 13, 17, 21).
- *UNIX and Linux System Administration Handbook* — Nemeth et al. : référence d'administration.
- *The Linux Programming Interface* — Michael Kerrisk : appels système, processus, signaux (module 07, 18, 20).
- *Systems Performance* — Brendan Gregg : méthode USE, outils d'observation (module 18).
- *Site Reliability Engineering* et *The Site Reliability Workbook* — Google (gratuits en ligne) : SLO, alertes, post-mortems (modules 23, 24).
- *Ansible: Up and Running* — Lorin Hochstein ; *Terraform: Up & Running* — Yevgeniy Brikman (modules 22).
- *Pro Git* — Scott Chacon (gratuit, <https://git-scm.com/book>).

## Documentation officielle
- Pages de manuel (`man`), `info`, `/usr/share/doc`, `tldr` (exemples rapides).
- Noyau : <https://docs.kernel.org> · systemd : <https://www.freedesktop.org/software/systemd/man/> · Debian : <https://www.debian.org/doc/> · Ubuntu Server : <https://documentation.ubuntu.com/server/> · RHEL : <https://docs.redhat.com> · ArchWiki : <https://wiki.archlinux.org> (excellent, utile pour toutes les distributions).
- nginx : <https://nginx.org/en/docs/> · HAProxy : <https://docs.haproxy.org> · Prometheus : <https://prometheus.io/docs/> · Ansible : <https://docs.ansible.com> · Docker : <https://docs.docker.com> · Podman : <https://docs.podman.io> · nftables : <https://wiki.nftables.org>.

## Pratique
- Un labo personnel : VM jetables (ce dépôt), un petit serveur à la maison (Raspberry Pi, vieux PC), instances cloud gratuites ou peu coûteuses.
- Plateformes d'exercices : OverTheWire Bandit (ligne de commande, en jouant), Linux Journey, KodeKloud, Killercoda, Root Me / TryHackMe / Hack The Box (sécurité, avec autorisation et règles de la plateforme).
- Contribution : corriger de la documentation, rédiger des rapports de bug, participer à des projets libres.

## Outils recommandés
`tmux`, `vim`/`nvim`, `ripgrep` (`rg`), `fd`, `fzf`, `bat`, `jq`, `yq`, `htop`/`btop`, `ncdu`, `shellcheck`, `shfmt`, `asciinema`, `direnv`, `pre-commit`, `ansible-lint`, `yamllint`, `hadolint`, `trivy`.

## Veille
- Newsletters : Linux Weekly News (LWN), Ubuntu Weekly Newsletter, SRE Weekly, DevOps Weekly.
- Bulletins de sécurité : Ubuntu Security Notices, Debian Security Advisories, Red Hat CVE, CERT-FR.
- Conférences et vidéos : FOSDEM, KubeCon, DevOpsDays, SREcon, chaînes des communautés francophones.

## Communautés
- Forums et Q&R : Unix & Linux Stack Exchange, Server Fault, Ask Ubuntu, forums des distributions, Discord/Matrix de projets.
- Groupes locaux : associations d'utilisateurs de logiciels libres (LUG), meetups DevOps/SRE.

## Se former sur la suite
Kubernetes (CKA), Terraform, observabilité (Prometheus/Grafana/Loki/OpenTelemetry), sécurité (CIS, SELinux, forensics), réseau (BGP/OSPF avec FRR), bases de données (PostgreSQL), programmation système (Python, Go, Rust, C).
